# Lessons Learned

- **macOS Chrome TCC Protection (`com.apple.macl`)**: Modern macOS restricts `~/Library/Application Support/Google/Chrome` with `PermissionError: [Errno 1] Operation not permitted` unless the terminal app has Full Disk Access. Never silently swallow `PermissionError` on top-level roots — track, collapse child denials, and present actionable Full Disk Access instructions.
- **Locale-dependent CLI numeric output**: macOS `ps -A -o %cpu=` emits decimal commas (e.g. `76,4`) under non-English locales such as `pt_BR`. Always pass `LC_ALL=C` when invoking macOS CLI utilities for parsing.
- **Browser game storage layout**: 6 GB+ browser games do not live solely in HTTP Cache; they split across `IndexedDB` (paired `.leveldb` + `.blob` dirs that must be deleted atomically), `WebStorage/<bucket_id>` (OPFS/Quota buckets mapped in `QuotaManager` SQLite), `Service Worker/CacheStorage`, `File System`, `blob_storage`, `Code Cache/wasm`, and `DawnWebGPUCache`. Reading `QuotaManager` with `file:...?mode=ro&immutable=1` avoids locking Chrome's SQLite DB.
- **Avoid dry-run double counting**: When multiple cleanup operations can touch overlapping browser cache trees (`browser_games` and `browsers`), run `browser_games` first and track claimed realpaths so neither live nor `--dry-run` double-scans or double-counts the same cache.
- **Single-file `.command` in Python on macOS**: A `.command` file with `#!/usr/bin/env python3`, `+x`, and `sys.dont_write_bytecode = True` works natively on Finder double-click (launching the interactive UI when invoked with no arguments in a TTY) and as a direct CLI executable when given flags, avoiding multiple confusing launcher files and `__pycache__` clutter. When loading a non-`.py` module via `importlib` in tests, register it in `sys.modules` before `exec_module` so Python 3.9 `@dataclass` with `from __future__ import annotations` resolves its module namespace cleanly.
